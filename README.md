# 截图打码 · 网页版

一个 `index.html` 同时适配电脑和手机：**宽屏自动排成双栏（左预览 + 右设置），窄屏自动排成竖排**，
横屏手机则用紧凑双栏。图片全程在本机处理，不上传。由DeepseekHarness开发。

## 怎么打开

### 电脑

- 双击 **`启动网页版服务.bat`**：会自动打开 `http://127.0.0.1:8080/`，并显示手机可用的局域网地址。
- 或者直接打开 `index.html`。

### 手机

1. 电脑上双击 `启动网页版服务.bat`，记下窗口里的地址，例如 `http://192.168.4.208:8080/`。
2. 手机连同一个 Wi-Fi，浏览器打开这个地址。
3. 点浏览器菜单 →「添加到主屏幕」，之后就像 App 一样使用。
4. 也可以直接下载 `index.html` 打开使用，或访问 <https://apx201.github.io/Screenshots_blur_web>。

## 怎么用

1. 选图：点「选择图片」多选；**电脑上还可以直接把图片拖进窗口，或按 Ctrl+V 粘贴截图**。
2. 默认已框好左下角 UID：拖方框移动、拖四角缩放；「区域放大」条可 1:1 看效果并直接拖动微调。
3. 选打码方式（高斯模糊 / 马赛克 / 纯色），拖「模糊强度」，强度按图片宽度换算，默认 7。
   - 选「纯色」时会多出一行颜色：点**色块**弹出系统取色器，或直接输入 `#ff5a5a`、`rgb(255,90,90)`。
4. 输出文件名：
   - **前缀**：填 `我的世界`，这批图就叫 `我的世界 …`；留空则沿用原文件名。
   - **后缀**：默认 `_已打码`，可改可清空。
   - **顺序编号**：按列表顺序在末尾加「空格 + 序号」，如 `我的世界 1`、`我的世界 2`；可设起始、补零。
   - **无损 PNG**（默认勾选）：导出 `.png`，打码区外的像素与原图完全一致；取消则按原格式导出（JPG 画质 95）。
   - 右侧「示例」会实时显示结果。
5. 下载：
   - **电脑**：`下载这张` 直接存到浏览器下载目录（默认「下载」文件夹）；多张用 `下载全部` 打包成 `打码结果.zip`。
   - **iOS**：同样直接下载，Safari 会存到「文件 → 下载」；想进相册可在「文件」里打开图片 → 分享 →「存储图像」。
   - **Android**：下载到「下载」文件夹。
   - 任何设备都**不会**弹系统分享面板。
6. 多张图片：缩略图切换，右上角 × 移除。

### 快捷键（电脑）

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+O` | 选择图片 |
| `Ctrl+S` | 下载当前这张 |
| `Ctrl+V` | 粘贴剪贴板里的截图 |
| `Delete` | 删除选中的打码区域 |

## 和 Windows 桌面版（Tkinter）的区别

| | 桌面版 `截图打码工具` | 网页版 |
| --- | --- | --- |
| 平台 | 仅 Windows | Windows / macOS / iOS / Android |
| 界面 | Tkinter 原生窗口 | 网页，Ore UI 风格 |
| 模糊算法 | Pillow GaussianBlur | Canvas 三次盒式模糊（等效高斯） |
| 边缘羽化 | 可调 | 固定硬边 |
| 批量输出 | 写入本地文件夹 | 直接下载 / ZIP |
| 画质 | 默认无损 PNG，可切 JPG/WebP 并调画质 | 默认无损 PNG，取消后按原格式导出（JPG 画质 95） |
| 离线 | 是 | 是（本地文件或已缓存） |

两个版本的默认区域与强度换算完全一致；命名、无损、纯色颜色等设置也一致，结果可混用。

## 注意

- 页面不需要联网，也不会把图片传到任何服务器。
- 默认输出无损 PNG，文件会比 JPG 大（3168×1440 约 0.5–2.3 MB）；想要小体积就取消「无损 PNG」。
- iPhone 的 HEIC 照片在部分系统版本里浏览器无法解码，建议用截图（PNG）或先转 JPG。
- 一次处理很多超大图（比如 20 张 4K）会占内存，建议分批。
- 文件：`index.html`（全部功能，单文件）+ `启动网页版服务.bat`（局域网打开用）。
