# 截图打码 · 网页版（PC / 手机通用）

一个 `index.html` 同时适配电脑和手机：**宽屏自动排成双栏（左预览 + 右设置），窄屏自动排成竖排**，
横屏手机则用紧凑双栏。界面沿用 Ore UI 暗色风格，图片全程在本机处理，不上传服务器。

![PC 布局](界面预览.png)

![手机布局](手机预览.png)

## 一、布局怎么自适应

| 屏幕宽度 | 布局 |
| --- | --- |
| ≥ 900px（电脑 / 平板横屏） | 左侧大预览 + 右侧设置栏（含日志），底部按钮吸底 |
| 700–899px | 上下排布，预览在上、设置在下 |
| < 700px（手机竖屏） | 手机竖排：预览 + 底部设置面板 |
| 横屏手机（高 ≤ 540px） | 紧凑双栏，隐藏放大条与日志，保证强度滑块可见 |

拖动窗口大小会实时重排，不需要刷新。

## 二、怎么打开

### 电脑

- 双击 **`启动网页版服务.bat`**：会自动打开 `http://127.0.0.1:8080/`，并显示手机可用的局域网地址。
- 或者直接双击 `index.html`（Chrome / Edge 打开即可，功能完全一样）。

### 手机

1. 电脑上双击 `启动网页版服务.bat`，记下窗口里的地址，例如 `http://192.168.4.208:8080/`。
2. 手机连同一个 Wi-Fi，浏览器打开这个地址。
3. 点浏览器菜单 →「添加到主屏幕」，之后就像 App 一样使用。

> 电脑关机后地址失效；想长期使用，可把 index.html 传到任意静态托管（GitHub Pages、Netlify Drop 等）。

## 三、怎么用

1. 选图：点「选择图片」多选；**电脑上还可以直接把图片拖进窗口，或按 Ctrl+V 粘贴截图**。
2. 默认已框好左下角 UID：拖方框移动、拖四角缩放；「区域放大」条可 1:1 看效果并直接拖动微调。
3. 选打码方式（高斯模糊 / 马赛克 / 纯色），拖「模糊强度」，强度按图片宽度换算，默认 7。
4. 下载 / 保存：
   - **电脑**：按钮显示为「下载这张」，点一下直接存到浏览器的下载目录（默认「下载」文件夹）；
     多张用「下载全部」打包成 `打码结果.zip`。电脑浏览器**不会**弹系统分享面板。
   - **iOS**：`保存这张` → 分享面板 →「存储图像」进相册。
   - **Android**：`保存这张` → 分享面板选相册，或下载到「下载」目录。
   - 只有手机/平板会调用系统分享；分享不可用时自动退回下载。
5. 多张图片：缩略图切换，右上角 × 移除。

### 快捷键（电脑）

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+O` | 选择图片 |
| `Ctrl+S` | 保存当前这张 |
| `Ctrl+V` | 粘贴剪贴板里的截图 |
| `Delete` | 删除选中的打码区域 |

## 四、和 Windows 桌面版（Tkinter）的区别

| | 桌面版 `截图打码工具` | 网页版 |
| --- | --- | --- |
| 平台 | 仅 Windows | Windows / macOS / iOS / Android |
| 界面 | Tkinter 原生窗口 | 网页，Ore UI 风格 |
| 模糊算法 | Pillow GaussianBlur | Canvas 三次盒式模糊（等效高斯） |
| 边缘羽化 | 可调 | 固定硬边 |
| 批量输出 | 写入本地文件夹 | 分享 / 下载 / ZIP |
| 离线 | 是 | 是（本地文件或已缓存） |

两个版本的默认区域与强度换算完全一致，结果可混用。

## 五、注意

- 页面不需要联网，也不会把图片传到任何服务器。
- iPhone 的 HEIC 照片在部分系统版本里浏览器无法解码，建议用截图（PNG）或先转 JPG。
- 一次处理很多超大图（比如 20 张 4K）会占内存，建议分批。
- 整个应用只有 `index.html` 一个文件，可以随意复制、改名、备份。
